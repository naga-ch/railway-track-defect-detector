# Security Policy

## Supported versions

Security fixes apply to the latest repository state. This research prototype does not currently publish supported release branches.

## Reporting a vulnerability

Do not publish credentials, private footage, or an exploitable vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. Otherwise contact the repository owner privately through GitHub and include the affected file, impact, and a safe reproduction description.

Do not include API keys, passwords, Wi-Fi credentials, SSH keys, or private camera images in reports. The dashboard is intended to bind to `127.0.0.1`; changing it to listen on a network interface can expose camera feeds and control endpoints.
