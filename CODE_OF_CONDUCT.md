# Code of Conduct

We want participation in this project to be respectful, constructive, and welcoming.

Examples of expected behavior include being considerate of others, discussing technical disagreements with respect, accepting feedback, and focusing criticism on ideas and code rather than people.

Harassment, personal attacks, discriminatory language, and publishing another person's private information without consent are not acceptable.

Project maintainers may edit or remove contributions that violate this standard and may restrict participation when needed. Report conduct concerns privately to the repository owner through GitHub. Use the process in [`SECURITY.md`](SECURITY.md) for security issues.
